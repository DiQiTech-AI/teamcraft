Connect

This console talks only to the local TeamCraft API (Query M3-02, SSE M3-03, Command M3-04). Paste the session token printed by teamcraft-api --print-token above and press Save. The token is kept only in this browser tab (sessionStorage) and is never written to disk or to the URL by this page.

Closing this page does not pause anything: scheduling, tasks and wakes live server-side and continue without any connected client.
